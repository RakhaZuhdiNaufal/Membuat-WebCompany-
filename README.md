# ☕ Kopi Senja - Company Profile Website

![Kopi Senja Preview](landing-hero.jpg) <!-- Ganti dengan screenshot hero jika ada -->

Kumpulan kode sumber (source code) untuk website **Company Profile Kopi Senja**. Proyek ini merupakan sebuah website profil perusahaan kedai kopi artisanal modern yang menonjolkan estetika premium, desain responsif, dan animasi yang mulus.

## ✨ Fitur Utama

- **Desain Premium & Elegan:** Menggunakan palet warna khas kopi (Coklat, Krem, Off-white) untuk memberikan nuansa hangat dan eksklusif.
- **Bilingual (ID / EN):** Mendukung fitur multibahasa secara dinamis menggunakan Vanilla JavaScript tanpa harus memuat ulang halaman (*real-time translation*).
- **Animasi & Transisi Halus:** Menggunakan CSS transitions dan keyframes untuk efek *fade-in*, transisi halaman, *hover effects*, dan interaksi mikro yang mewah tanpa menggunakan *library* eksternal.
- **Responsif Sepenuhnya:** Tampilan disesuaikan secara dinamis (*Mobile-first approach*) menggunakan CSS Flexbox dan Grid untuk berbagai ukuran layar (Desktop, Tablet, Mobile).
- **Sistem Navigasi Dinamis:** Navbar interaktif dengan efek *glider* yang meluncur mulus mengikuti posisi menu aktif.

## 🛠️ Teknologi yang Digunakan

Website ini dibangun menggunakan stack *Frontend* murni (Vanilla) untuk menjaga performa tetap cepat dan ringan:
- **HTML5:** Struktur semantik yang rapi dan SEO-friendly.
- **CSS3 (Vanilla):** *Styling*, animasi (*keyframes* & *transitions*), variabel warna (CSS Custom Properties), layout (Flexbox & Grid).
- **JavaScript (Vanilla):** Logika DOM *manipulation*, fitur multibahasa (i18n), interaksi *navbar*, dan animasi *scroll*.

## 📂 Struktur Halaman Utama

1. **`landing.html`:** Halaman Utama (Home) yang menampilkan identitas *brand*, hero *section*, cerita singkat, dan *call-to-action*.
2. **`about.html`:** Halaman Tentang Kami yang menceritakan sejarah berdirinya Kopi Senja, filosofi biji kopi, dan foto tim.
3. **`Index.html` (Menu):** Katalog menu minuman (Kopi, Non-Kopi) dan kue pendamping dengan desain grid yang menarik.
4. **`careers.html`:** Halaman Karir yang memuat *timeline* jenjang karir (mulai dari merintis hingga manajer) dan daftar lowongan pekerjaan yang sedang dibuka.

## 🚀 Cara Menjalankan (How to Run)

Karena ini murni statis, tidak diperlukan instalasi *package* atau proses *build*.
1. *Clone* atau *download* repository ini.
2. Buka folder proyek di komputer Anda.
3. Anda bisa menggunakan ekstensi **Live Server** di VS Code, atau langsung klik ganda (buka) file `landing.html` di *browser* apa saja (Chrome, Firefox, Safari).
